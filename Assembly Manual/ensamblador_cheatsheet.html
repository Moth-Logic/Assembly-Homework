Directivas de datos reservar espacio vs. definir valores ya inicializados
NASMGASTamañoQué hace
db.byte1 byteDefine uno o más bytes con valor inicial. db "Hola", 10 = string + newline.
dw.hword / .short2 bytesDefine un valor de 16 bits ya inicializado.
dd.word / .long4 bytesDefine un valor de 32 bits ya inicializado.
dq.quad8 bytesDefine un valor de 64 bits ya inicializado.
dt—10 bytesDefine un extendido de 80 bits (poco usado, coma flotante x87).
resb.skip / .space (en .bss)N bytesReserva N bytes SIN inicializar (van a 0 por default en Linux). No ocupa espacio en el archivo, solo en memoria al cargar.
resw.skip N*2N×2 bytesReserva N palabras de 16 bits sin inicializar.
resd.skip N*4N×4 bytesReserva N dobles palabras de 32 bits sin inicializar.
resq.skip N*8N×8 bytesReserva N cuádruples palabras de 64 bits sin inicializar.
—.lcomm nombre, NN bytesForma "GAS nativa" de reservar N bytes en .bss (equivalente directo a resb, más idiomático que .skip).
—.ascii "texto"stringString SIN null terminator automático (como db "texto" en NASM).
—.asciz "texto"string + \0String CON null terminator automático al final (útil si vas a usar funciones estilo C que esperan '\0').
times N db X.fill N, 1, XN bytesRepite un valor N veces (ej: rellenar con ceros, padding).
equ.equ / =0 bytesConstante en tiempo de ensamblado — sustitución de texto, no ocupa memoria.
$.—"Dirección actual" — usado para calcular longitudes: len equ $-msg
.align N.align N / .balign N—Alinea la siguiente dirección a un múltiplo de N (rendimiento de acceso a memoria).
Directivas estructurales / de ensamblado
NASMGASQué hace
section .data / .bss / .text.section .data / .bss / .textCambia a qué región de memoria van las líneas siguientes.
global etiqueta.global etiqueta / .globl etiquetaHace visible una etiqueta para el linker (típicamente _start).
extern etiqueta.extern etiquetaDeclara que una etiqueta está definida en OTRO archivo (para linkear varios .o juntos).
%define NOMBRE valor.equ NOMBRE, valorConstante simbólica — sustitución de texto en tiempo de ensamblado.
%macro nombre N ... %endmacro.macro nombre arg1,arg2 ... .endmDefine una macro: bloque de instrucciones reutilizable con parámetros, expandido inline al ensamblar (no es una función — no hay call/ret, es copy-paste).
%include "archivo.inc".include "archivo.s"Inserta el contenido de otro archivo fuente antes de ensamblar.
bits 64 / bits 32(se define por el flag del ensamblador)Le dice al ensamblador si generar código de 64 o 32 bits.
; comentario@ comentario  o # / //Todo lo que sigue en la línea se ignora al ensamblar.
Movimiento de datos
NASM (x86-64)GAS (ARM AA32)Qué hace
mov dst, srcmov dst, src / mov dst, #immCopia un valor (registro, memoria o inmediato) al destino. En ARM, el ORIGEN memoria NO es válido — para eso están ldr/str.
mov reg, [mem]ldr reg, [dir] / ldrb (byte) / ldrh (16 bits)Carga (load) un valor DESDE memoria a un registro. ARM obliga a separar esto de mov (arquitectura load-store).
mov [mem], regstr reg, [dir] / strb (byte) / strh (16 bits)Guarda (store) un registro EN memoria. Mismo motivo — nunca se opera memoria directo en ARM.
movzx dst, srcldrb / ldrh (ya hacen zero-extend solos)Carga un valor MÁS chico (byte/word) a un registro más grande, rellenando con CEROS los bits extra.
movsx dst, srcldrsb / ldrshIgual que movzx pero rellena con el BIT DE SIGNO (para números negativos con signo).
lea dst, [expr]ldr dst, =etiqueta / add dst, base, #offsetCarga la DIRECCIÓN calculada (no el contenido) — "load effective address". Muy usado para calcular direcciones sin acceder a memoria.
push regpush {reg} o stmfd sp!, {...}Apila un valor: decrementa el stack pointer y guarda el registro en la pila.
pop regpop {reg} o ldmfd sp!, {...}Desapila: lee el tope de la pila al registro e incrementa el stack pointer.
xchg a, b(no existe directo — se hace con un registro temporal)Intercambia el valor de dos operandos entre sí.
Aritmética
NASM (x86-64)GAS (ARM AA32)Qué hace
add dst, srcadd dst, src1, src2Suma. x86: dst = dst+src (destructivo). ARM: dst = src1+src2 (no destructivo).
sub dst, srcsub dst, src1, src2Resta: dst = dst−src (x86) o dst = src1−src2 (ARM).
—rsb dst, src1, src2"Reverse subtract" — dst = src2−src1 (invertido; útil porque el 2do operando en ARM puede llevar shifts, el 1ro no).
inc regadd reg, reg, #1Incrementa en 1 (ARM no tiene inc/dec dedicados, se hace con add/sub #1).
dec regsub reg, reg, #1Decrementa en 1.
neg regrsb reg, reg, #0Cambia el signo (complemento a 2): reg = −reg.
mul src unsignedmul dst, src1, src2Multiplicación sin signo. x86: rax = rax*src (resultado en rdx:rax). ARM: dst = src1*src2, de 3 operandos.
imul src/dst,srcmul (ARM no distingue con/sin signo en mul de 32b)Multiplicación con signo.
div src unsignedudiv dst, src1, src2División sin signo. x86: divide rdx:rax entre src, cociente en rax, resto en rdx.
idiv srcsdiv dst, src1, src2División con signo.
Lógica y manipulación de bits
NASM (x86-64)GAS (ARM AA32)Qué hace
and dst, srcand dst, src1, src2AND bit a bit. Útil para "apagar" bits específicos (máscaras).
or dst, srcorr dst, src1, src2OR bit a bit. Útil para "prender" bits específicos.
xor dst, srceor dst, src1, src2XOR bit a bit. Invierte (toggle) los bits marcados con 1 en el operando. También: xor reg,reg = poner el registro en 0 rápido.
not regmvn dst, srcInvierte TODOS los bits (complemento a 1). mvn = "move NOT".
shl dst, N o sallsl dst, src, #NShift lógico a la IZQUIERDA: multiplica por 2^N, rellena con ceros por la derecha.
shr dst, Nlsr dst, src, #NShift lógico a la DERECHA: divide por 2^N sin signo, rellena con ceros por la izquierda.
sar dst, Nasr dst, src, #NShift ARITMÉTICO a la derecha: divide por 2^N CON signo — rellena con el bit de signo, no con cero (preserva negativos).
rol dst, N(no directo — se compone con lsl+orr)Rota bits a la izquierda — los que "se salen" por arriba reentran por abajo.
ror dst, Nror dst, src, #NRota bits a la derecha — los que se salen por abajo reentran por arriba.
Comparación
NASM (x86-64)GAS (ARM AA32)Qué hace
cmp a, bcmp a, bCalcula a−b internamente y actualiza flags, SIN guardar el resultado en ningún lado. Base de todo salto condicional.
test a, btst a, bCalcula a AND b internamente (sin guardar), solo para ver si el resultado da cero — típico para "¿está prendido este bit?".
—cmn a, b"Compare negative" — calcula a+b internamente, actualiza flags (equivalente a comparar contra un negativo).
—teq a, bCalcula a XOR b internamente — útil para ver si dos valores son EXACTAMENTE iguales, ignorando el flag de overflow.

Llamadas al sistema y control de flujo
NASM (x86-64)GAS (ARM AA32)Qué hace
syscallsvc 0Cede el control al kernel para ejecutar la syscall cuyo número está en rax/r7.
int 0x80 x86 32-bit clásico(svc 0 es el equivalente moderno de ARM)Forma antigua de invocar syscalls en x86 de 32 bits vía interrupción software.
nopnopNo hace nada — ocupa un ciclo/espacio, usado para alineación o padding.
hlt(no aplica en espacio de usuario)Detiene el CPU (solo válido en modo kernel/privilegiado).
